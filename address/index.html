ADDRESS 是怎么工作的？

公式里要用某个格子，位置却要算了才知道：商品挪一行、插一列，手写的 C5 转眼就指错门。ADDRESS 拿行号和列号当场拼出一个合法地址，位置变了，地址跟着变。

ADDRESS 用行号和列号拼出一个单元格地址文本。参数依次是：row_num 行号（1 到 1048576）、column_num 列号（1 到 16384）、abs_num 锁定模式（1 全锁、2 锁行、3 锁列、4 全放，默认 1）、a1 样式（TRUE 为 A1 样式，FALSE 为 R1C1 样式）、sheet_text 表名前缀。执行分四步：先读入行号列号；A1 样式下把列号按 26 个字母一组循环转换成字母，26 之后进位，27 是 AA，最后一列 16384 是 XFD，行号原样保留；再按锁定模式在列字母或行号前插入美元符，R1C1 样式改用 R 和 C 加数字，方括号表示相对引用；最后拼接表名前缀与感叹号得到结果。结果是一段文本，例如 $C$5；要取该格子的值需套 INDIRECT。行号或列号小于 1、或超出工作表行列边界时返回 #VALUE!；文本地址直接参与加法也会返回 #VALUE!。页面实验区可以改行列号、点表格任意数据格换目标、切换四种锁定档、切换 R1C1 样式、给地址加库存表表名，并演示忘写表名时跨表取数静默取错值的情形。

行号 列号 原料是纯数字。点表格里任意数据格，也能把目标换过去。
列号尺
26 个字母用完就进位：26 是 Z，27 是 AA；最后一列 16384 是 XFD。输 0 或 16385 看它怎么报错。
锁定档 和选中引用后按 F4 循环的顺序一致：1 全锁、2 锁行、3 锁列、4 全放。
引用样式 R1C1 行列全是数字，方括号 = 相对（会随公式位置跑）。
表名 跨表引用的前缀，表名含空格时 Excel 会自动包上单引号。
想取库存表的货，却忘写表名：=INDIRECT(ADDRESS(5,3)) 默认在当前表取数——拿到 34（销售表 C5），真实要的是 220（库存表 C5）， 差了 186，全程不报错。
ADDRESS 口诀（截图存好）
  • 行列报数字，出来是门牌：=ADDRESS(5,3,1) → $C$5
  • 锁定问 F4：1 全锁 · 2 锁行 · 3 锁列 · 4 全放
  • 列过 26 会进位：27 = AA，最后一列 XFD（16384）
  • R1C1 全用数字，方括号 = 会跑：R5C[3]
  • 门牌是文本，进门取货找 INDIRECT；跨表别忘了表名
